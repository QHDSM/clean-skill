# 应用、个人文件、云同步与重复项

## 决策表

| 类别 | 确认依据 | 授权后可做 | 保留 |
|---|---|---|---|
| 应用缓存 | 已识别应用、其实际配置目录和支持的清理方法 | 清理明确可重建且未使用的缓存 | 用户设置、账户状态、离线用户数据 |
| 浏览器 | 当前配置及官方清理入口 | 仅已授权的缓存类型 | Cookie、密码、历史、收藏夹、整个 profile |
| 聊天/邮件/游戏 | 应用内存储管理及本地/云状态 | 仅明确选定可再下载内容 | 聊天记录、附件唯一副本、邮件、存档 |
| 日志 | 所属应用、轮转和保留要求 | 明确授权且无活动写入的可清理日志 | 审计、故障证据、活动日志 |
| 下载/安装包/压缩包 | 文件路径、大小、时间 | 用户明确选择的范围 | 默认全部保留；旧和大不证明无用 |
| 照片/视频/文档 | 元数据即可分析 | 用户明确选择的范围 | 不读取内容推断价值，不假定存在备份 |
| 备份/恢复 | 备份软件及恢复用途 | 单独授权的支持操作 | 不以“其他地方似乎有副本”为由清理 |

扫描分类是推断，报告应说明依据及不确定性。扩展名可以伪装，不执行扫描出来的程序或脚本来“识别文件”。

## 云同步

先确认提供商、实际同步根和同步状态。默认保留整个同步数据范围。在线占位符显示的逻辑大小不代表本地占用；读取其内容可能触发下载，因此扫描器跳过重解析/离线/召回属性。

如用户单独选择“释放本地空间”，使用提供商支持的入口，并确认同步已完成且用户接受离线不可用。不要将普通文件删除替代为“仅释放本地”；同步删除可能传播到云端和其他设备。

## 重复文件

仅在明确启用时按大小筛选，再用 SHA-256 分组。扫描器避免把同一文件的硬链接视为独立重复副本；遇到文件变化则报错。哈希相同不是删除许可。保留哪个文件由用户决定，特别注意项目、同步、备份和应用依赖。

重复分析会读取内容，I/O 成本高，元数据（例如访问时间）可能由系统更新。它不应成为全机分析的默认步骤。

## 候选和执行记录

候选：路径/所属应用、测量大小、用途依据、操作与范围、是否永久删除、影响和待确认项。

执行记录：原目标、操作时间、方法/参数范围、结果、错误/跳过原因。不要记录文件内容或认证材料。未执行的图形界面操作不能记为成功。
